# 功能清单与页面截图位

本文用于沉淀 QuickAgentSilva 的必要功能清单与页面展示位，便于产品介绍、验收与对外演示复用。

## 1. 必要功能清单（MVP）

### A. 工作流编辑与配置

- 画布节点拖拽、连线、缩放、平移
- 节点选中删除、框选多选
- 节点库检索与分类浏览
- 节点配置面板（参数、输入输出映射）
- 工作流保存与重新加载

### B. 运行与调试能力

- 一键触发工作流运行（表单触发）
- 聊天入口触发流式运行（SSE）
- 节点级执行状态实时反馈
- 运行失败可定位到节点日志
- 支持历史运行回看

### C. 观测与追踪

- 运行列表检索和分页
- 节点日志查看（输入/输出/耗时）
- 执行轨迹查看（trace 事件）
- 运行最终状态与错误信息展示

### D. 模板与复用

- 从现有工作流保存模板
- 模板列表浏览、搜索与删除
- 模板一键应用创建新工作流

### E. 知识库能力

- 知识库创建与管理
- 文本分块入库
- 检索测试与结果预览
- 检索参数调优能力（用于效果验证）

### F. Agent 工程化能力

- Agent 节点可纳入统一工作流编排，不依赖前端写死流程
- 支持聊天流式触发与节点级实时反馈
- 支持断点续跑和单步调试，便于复杂流程排障
- 支持运行历史回放，便于复现问题和效果对比

## 3. 对外介绍建议（可直接复用）

- 平台价值：把 Agent 构建从“代码串联”升级为“可视化编排 + 可观测运行”
- 核心能力：编排、运行、观测、复用、知识增强五位一体
- 演示路径：新建工作流 -> 配置节点 -> 聊天触发 -> 查看日志/trace -> 保存模板复用
